🏗️ Construction Intake – Apps Script Setup

Follow these steps to deploy the backend that powers the Construction Career Pre-Apprenticeship Intake Form.

📋 Setup Steps

  1. 1 Go to Google Apps Script and click + New Project
  2. 2 Delete everything in the default Code.gs file
  3. 3 Click the "Copy All Code" button below — it copies the entire script to your clipboard
  4. 4 Paste into the Apps Script editor (Ctrl+V / ⌘+V)
  5. 5 Click Deploy → New deployment
  6. 6 Select type: Web app
  7. 7 Set Execute as: Me
  8. 8 Set Who has access: Anyone
  9. 9 Click Deploy and authorize when prompted
  10. 10 Copy the Web App URL and send it back — it will be embedded in the intake form
⚠️ Important: When Google asks for permissions, click "Advanced" → "Go to (project name)" → "Allow". The script needs access to Sheets and Drive to save submissions and uploaded files.
